# Lizard Game

Toon-styled 3D browser game: a small lizard exploring a miniature natural world.
Three.js + TypeScript for rendering, Rapier (`@dimforge/rapier3d-compat`) for physics, Vite for builds.

## Commands

- `npm run dev` — dev server
- `npm run typecheck` — TypeScript check
- `npm run build` — typecheck + production build to `dist/`
- `npm run assets` — regenerate GLB models from `assets-src/`
- `npm test` — Playwright: builds, serves, boots the game in headless Chromium (about a minute and a half with 2 workers; CI splits it across 5 jobs)
- `npm run screenshots` — the same, also saving screenshots to `test-results/screenshots/`

In Claude cloud sessions Chromium is preinstalled; do not run `playwright install`.

## Conventions

- World units are metres at real scale: the lizard is ~0.19 m long, snout to tail tip. Keep camera near-plane and fog tuned for that.
- Physics is the source of truth. Rapier steps at a fixed 60 Hz in `src/loop.ts`; meshes only follow bodies and interpolate between steps. A frame's time is never negative (after a long task at load, the first frame's timestamp can come before the loop started), or animations step backwards and start-up drifts.
- Keep systems as plain TypeScript modules, one concern per file. No ECS framework or engine layer.
- Expose anything a test needs to check on `window.__game` (`src/debug/testHooks.ts`) rather than testing pixels.
- Keep the suite fast (under 2 minutes in CI). Tests open the game with `?test`: no real-time loop and nothing drawn unless a test asks (`advance(n, true)`, or the `screenshot` helper, which only shoots with `SCREENSHOTS=1`), since on the software renderer a page that has drawn takes over a second to close. `bootGame` pauses the other iguanas and the crabs (hook `pause`) unless a test asks for them (`{ iguanas: true, crabs: true }`, or just the iguanas it uses, `{ iguanas: [0] }`): each iguana costs about as much as the player. Keep the default 60 s timeout rather than raising it per test; a test that needs more is simulating more than it checks.
- Models are generated by Blender Python scripts in `assets-src/` and exported as GLB to `src/assets/` (committed). Run `npm run assets` after editing a script; it needs `pip install -r assets-src/requirements.txt` (the `bpy` package is Blender as a Python module, Python 3.11 only).
- Preserve physics/update ordering and deterministic random-number consumption when refactoring.
- Gravity stays vertical. No wall/ceiling traversal or full runtime foot IK. The physics capsule stays straight; visual fitting follows the surface. Restore the last clip pose before mixing, never the rest pose.
- Preserve the documented Rapier tolerances and exact-surface queries; they prevent movement and animation regressions at this small scale.
- Debug hook implementations live in `src/debug/createTestHooks.ts`; their public contract is in `testHooks.ts`. Main owns mutable input/view overrides and the frame-driving callbacks. Tests share `tests/helpers/bootGame.ts`; hawk scenarios explicitly enable the hawk.
- Shared animation initialization lives in `src/render/animationActions.ts`. Playback, restart and crossfade behavior remain creature-specific. Shared Blender helpers live in `assets-src/common.py`; geometry and random calls remain species-specific.
